## 验收配置

- MCU：STM32F429。
- SYSCLK/HCLK：100 MHz；APB1 PCLK：25 MHz；APB1 定时器时钟：50 MHz。
- TIM2：PSC=9、ARR=499、TRGO=Update，更新频率为 `50 MHz / ((9+1) × (499+1)) = 10 kHz`。
- ADC1：12 位、25 MHz ADC 时钟、144 周期采样时间、外部触发为 TIM2 TRGO。
- ADC circular DMA：512 个 `uint16_t` 样本，分成两个 256 点半区；每半区时间为 `256 / 10000 = 25.6 ms`。

## 本次测试结果

此前短时测试使用 Debug 固件、DAPLink 和示波器。DAPLink 观察到以下最大值；调试器随后以 SIGINT 暂停。按每个 DMA 半区 25.6 ms 估算，361 次 IRQ 对应约 `361 × 256 / 10000 ≈ 9.24 s` 的采集区间；测试起止的墙钟时间未单独记录。

| 项目 | 观测值 | 判定 |
|---|---:|---|
| DMA IRQ 次数 | 361 次 | 短时连续运行期间持续收到 DMA 事件 |
| `g_ecg_timing_max_process_cycles` | 146,978 周期 = 1.46978 ms | 单个采样块处理耗时 |
| `g_ecg_timing_max_ready_to_release_cycles` | 147,901 周期 = 1.47901 ms | DMA 发布到主循环归还的最长耗时 |
| DMA 半区重用周期 | 2,560,000 周期 = 25.6 ms | 验收上限 |
| `g_ecg_timing_max_dma_irq_cycles` | 526 周期 = 5.26 µs | DMA IRQ 处理函数耗时 |
| 示波器 PB7 IRQ 脉宽 | 约 5.7 µs | 与 DWT 测得的 IRQ 处理耗时基本相符 |
| 示波器 TIM2 同步参考 | 观测到约 100 µs 的参考边沿间隔 | 与 10 kHz 采样触发间隔相符 |

最大 ready-to-release 耗时为半区周期的约 **5.8%**，本次观测值留有约 **24.12 ms** 的余量。调试暂停前主程序仍运行在按键更新时间路径，未观察到覆盖错误处理路径。
