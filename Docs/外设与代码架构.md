# ECG_backend

## 1. LED 状态指示
- LED1/2/3 均为**高电平亮**，分别接 **PB6 / PB7 / PB14**，相关 GPIO 已配置。
- 用途：
  - LED1：标志运行。
  - LED2：标志错误或未稳定。
  - LED3：自由发挥。

## 2. 总线与外设
| 总线 | 频率 | 外设 |
|---|---|---|
| APB1 | 25 MHz | TIM2、TIM3、TIM4、TIM5、TIM6、TIM7、TIM12、TIM13、TIM14；USART2、USART3、UART4、UART5；SPI2、SPI3；I2C1、I2C2、I2C3 |
| APB2 | 50 MHz | TIM1、TIM8、TIM9、TIM10、TIM11；USART1、USART6；SPI1、SPI4、SPI5、SPI6；ADC1、ADC2、ADC3|

## 3. ECG 采集后端
- ADC1 由 **TIM2 以 10 kHz 触发**，转换 **IN12 通道（PC2）**。
- ADC1 自身频率 **25 MHz**，循环 DMA，DMA 开启中断，**half word** 宽度，采样时间 **144 cycle**。
- TIM2 输入时钟为 **50 MHz**（APB1 PCLK=25 MHz，定时器时钟为 PCLK×2）；PSC=9、ARR=499，更新频率为 50 MHz / ((9+1)×(499+1)) = **10 kHz**。
- ADC DMA 缓冲区为 **512 个 `uint16_t` 样本**，每半区 256 点（25.6 ms）；半满/全满回调分别发布前/后半区就绪事件，主循环有序消费并释放。32 位无符号样本计数按块连续递增。
- 采集模块检测 DMA 即将覆盖尚未消费或仍在处理的半区，并记录故障；目标板的持续采样、半区顺序、无丢块及最坏处理耗时仍需实测。

## 4. LCD 显示
- LCD 分辨率：**240 × 240**，SPI 通信。
- 引脚：
  - PF9：MOSI
  - PH6：SCK
  - PH13：OLED RESET
  - PH7：OLED data/command
- SPI 配置：**transmit only master、8 bits、MSB first、mode0**，已启动 DMA（**1 byte，normal**）。
- 注意：`lcd_init` 前要 `delay_init(100)`，其中 100 表示系统频率 **100 MHz**。LCD 和 DELAY 函数的 inc/src 在 `Drivers` 中。
- demo代码采用**阻塞 SPI** 。
- 为大批量像素传输（如初始化清屏）添加 `HAL_SPI_Transmit_DMA`，在保持 `lcd_init` 时序安全的前提下，把 CPU 从 SPI 逐字节搬运中解放出来。
- 滚动显示是计算密集型、时间驱动、小数据量，DMA 搬运不是瓶颈；DMA 留给清屏和大面积重绘，滚动逐列保持阻塞 SPI 简单又稳。

## 5. 按键与触发电平
- 按键Key1 / Key2接 **PG6 / PG7**，**输入上拉**，按下为低电平。
- 按键加入去抖和长按连调：采用**非阻塞状态机 + 时间戳**，以节约 MCU。

## 6. 心率计算
- 每搏计算一次，以可靠的 R 峰时间戳为基础。
- 每检测到一个有效 R 峰，就用它与前一个 R 峰的间隔计算一次瞬时心率：
  - `瞬时 BPM = 60,000 / RR间隔(ms)`
- 心率显示值做平滑，屏幕显示最近 **5 个有效 RR** 的平均数。
- R 峰检测：
  - 可调阈值的上穿作为候选点；
  - 在其后的短窗口确认局部最大值，得到 R 峰时间戳。
- 设置回差和不应期：
  - 只将 **410–1375 ms** 的 RR 间期纳入当前目标范围的稳定心率统计；对应约 **2.2–0.8 Hz**。
  - 启动初期数据不足时标为**未稳定**。
- 每搏峰峰值：按该搏区间内校准后的波形最大值减最小值计算。

## 7. 软件分层
1. **采样层**：ADC circular DMA 乒乓缓冲；中断只通知主循环缓冲区就绪。
2. **信号处理层**：
   - 10 kHz 采样到 1 kHz 前做抗混叠低通（求均值即可）。
   - 50 Hz 陷波在 1 kHz 处理链中使用 CMSIS-DSP `arm_biquad_cascade_df1_f32`，2 级 DF1 带阻滤波器；状态跨 DMA 块保留。接口接收 `float32_t` 数据，原地处理，不能把 `uint16_t` ADC 缓冲区直接当作浮点数据传入。
3. **事件层**：使用时间戳记录 R 峰；DMA 块边界不应影响 RR 间隔和波形连续性。
4. **显示层**：绘图区显示最近 2.4 秒，240 列约对应 **10 ms/列**；每列用该时间段内采样的 10 个点的 **min 与 max** 形成包络，避免抽稀时漏掉 QRS 尖峰。坐标轴静态绘制，擦除时恢复该列网格背景；写入指针以 10 ms/列往前走，擦除指针滞后写入指针 **30 列（300 ms）** 擦除，到达屏幕右侧后回到最左侧。

## 8. 显示与电压标定
- 纵轴标定电压：前端电路增益 **64 dB**，ADC 输入端偏置 **+1.5 V**，估算关系：
  - `ECG_mV = (ADC_V - 1.5 V) / 10^(64/20) × 1000`
- Vref 为 **3.3 V**、ADC 为 **12 位**，输入端每个 ADC 码约对应 **0.000508 mV** 的 ECG 电压。
- 阈值步进默认 **0.05 mV**（约等于 100 个 ADC 码），长按 **0.10 mV** 加速。
- 屏幕右下角显示心率与心电压峰峰值。
- 擦除恢复网格背景时要避免擦掉静态坐标轴；右下角文本区要与波形区分离，文本刷新不要每样本刷新。

## 9. 关键风险与实现约束
- 以下主要是 MCU 计算慢于 ADC 的考量，**验证前无需考虑**：
  - 10 kHz 下，若半缓冲 **256 点 = 25.6 ms**，主循环最坏处理时间必须小于该值，否则覆盖。
  - 覆盖不是 DMA 报错，而是静默发生：还没读的旧采样点被新采样点替换；表现为波形断裂、跳变；R 峰时间戳可能错位；RR 间期计算异常；显示包络 min/max 可能丢掉 QRS 尖峰；且可能偶发，调试时表现为“偶尔心率乱跳/波形缺一块”。
- 措施：
  - 中断只置标志；半满/全满中断里不要做滤波、绘图、I2C，只记录“哪半就绪”。
  - 避免长阻塞；LCD 用 DMA 后要检查单次 DMA 最长等待时间；长按连调不要用长延时。
  - SPI 用半传输中断；如果一次 DMA 传输包含多列数据，可以在 `HAL_SPI_TxHalfCpltCallback` 中开始准备下一半的数据，实现流水线化。
  - 例如对于 240 列逐列推进的场景，按“每 N 列一组”做 DMA，组内用半传输中断触发下一组的准备，比较平滑。
- 时间戳置零会破坏前一个 R 峰时间戳与 RR 计算；建议用**无符号 32 位采样计数自然回绕**，计算差值时处理无符号回绕。10 kHz 下 32 位约 **4.97 天**溢出，不必频繁置零。
- DMA 的半满/全满中断只是“缓冲区这半可以读了”的通知，不是“信号重新开始”的信号。滤波器历史、RR 间距、列包络累加器、采样时间戳都是连续数据流上的状态，必须用**静态变量跨块保留**。
